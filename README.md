# After You

A first-person psychological horror game for Roblox. The building remembers where you walk, and the thing living in it can only follow where someone has already been.

- `docs/` — research report, master implementation plan, vertical slice spec, task breakdown, changelog
- `src/` — Luau source (Rojo project: `default.project.json`)
- `tests/` — unit tests for pure logic (`luau tests/run.luau`)
- `AfterYou_Greybox.rbxlx` — ready-to-open greybox build (Studio > File > Open from File, then Play)

How to play and build the greybox: see [README_GREYBOX.md](README_GREYBOX.md).
